# 회사에서 옮겨 온 전달 블록

회사 PC의 캡처 세션이 찍은 전달 블록을 손으로 옮겨 적어 이 폴더에 둡니다. 블록에는 코드, 수, 시스템 이름, 커밋만 있으므로 커밋합니다.

## 파일 이름

`<YYYY-MM-DD>-<시스템>.md` (예: `2026-12-03-GSCM.md`). 같은 날 두 번이면 `-2`를 붙입니다.

## 양식

````markdown
# 2026-12-03 GSCM

- 날짜: 2026-12-03
- 시스템: GSCM

```
[전달] v2 · 6dbba10 · 변경없음 · GSCM · 캡처7 · 32분 ·K7
H01 DELPHI(14/16)   H02 FARPOINT   H03 LOW(4/0/85)   H04 INVOKE_ONLY(I3/V0/T0) ·3F
…
```

## 말로 덧붙인 것

사람이 기억으로 전한 내용(화면의 글자나 회사 정보는 쓰지 않음).
````

블록은 줄마다 끝의 ` ·`와 두 글자(확인 문자)까지 그대로 옮깁니다. 칸 사이 공백 수는 틀려도 됩니다.

## 읽기

```powershell
python survey.py --read-block docs\company-survey\feedback\2026-12-03-GSCM.md
```

파일에서 `[전달]`로 시작하는 블록을 찾아 줄마다 확인 문자를 다시 계산하고, 맞지 않는 줄 앞에 `오타?`를 붙입니다. 가설 판정마다 뜻과 집에서 할 일을, 캡처 줄마다 장면·구조 코드의 뜻을 풀어 씁니다. 모르는 코드는 `모르는 코드`로 표시합니다. 블록의 버전이 지금 코드와 다르면 알립니다. 코드의 뜻은 `../hypotheses.md`와 `../codes.md`에 있습니다.
